# 濟州島・兩人的四日自駕計畫

2026/10/24–10/27 濟州島旅行的互動規劃網站。這個資料夾是可直接部署的靜態網站；`index.html`、各個 `.js` / `.css` / `.json` 和 `assets/` 都是網站內容。沒有編譯步驟或外部套件安裝。

## 本機預覽

在此資料夾執行 `python -m http.server 8769`，開啟 `http://127.0.0.1:8769/`。不要直接用 `file://` 開啟，因為景點與照片資料需要透過 HTTP 讀取。

## 發布

公開 GitHub 儲存庫啟用 **Settings → Pages → Deploy from a branch → main / (root)** 後，推送到 `main` 便會自動重新發布。網站的預期網址為 `https://jasperlee1027.github.io/jeju-two-20261024/`；上線前請以 GitHub Pages 設定畫面顯示的網址為準。現有的 `chatgpt.site` 版本是舊站，兩者不會自動同步。

部署驗證：Codex Cloud 可推送 main，GitHub Pages 會在推送後自動重新建置。

## 編輯注意

- 網站以 hash 分頁，例如 `#car`、`#places`。資源使用相對路徑，部署在 GitHub Pages 專案子路徑仍可讀取。
- 地圖旁候選清單的多分店品牌預設收合，點開查看個別店點；地圖標點、分店ID與想去記錄保留，篩選先按店點套用再分組。
- 花費預設存於瀏覽器的 `localStorage`；加入同一份私人「共用花費連結」後，預估花費選項與自訂項目會自動同步。第一次由有完整紀錄的裝置建立資料；加入、合併、解決衝突前會留本機備份。離線修改稍後再同步，同欄衝突需手動選擇。連線金鑰與部署網址不放在公開程式碼，詳見 [共用花費說明](integrations/cost-sync/README.md)。
- 待辦和想去景點仍各自存於瀏覽器。「想去」可透過候選景點頁的「儲存／帶到其他裝置」複製清單連結，在另一裝置開啟後合併或取代。這是當下快照，後續勾選不自動同步，也不包含待辦、花費。從舊站換到新網址，舊站個人資料不會自動轉移。
- 共同規劃文件為 「新濟限挑戰😗💖」（私人文件，連結不放入公開儲存庫）。使用者要求網站更動同步到這份文件；若執行環境無文件編輯權限，應在交付時明確列出未同步的內容，不能聲稱完成。
- 已出票：兩人來回真航空 LJ764 / LJ941，實付 NT$26,598。住宿10/23–27四晚海景豪華套房、兩人NT$11,375已付款；Orcar MINI敞篷10/24 08:20–10/27 18:30（韓國時間）、82小時10分、NT$12,823已付款且含租車保險，方案與保障明細待核對。請勿將估價誤寫成已付款。


## 想去清單驗證

`node --test tests/wish-memory.test.cjs` 可驗證連結序列化、空白清單與無效輸入。網站仍不需安裝依賴或執行建置。

## 地圖連結

韓國地點保留Google地圖並提供Naver Map搜尋；有分店時帶入個別地址，照片出處不改成Naver來源。台灣監理站維持Google地圖。`node --test tests/map-links.test.cjs` 可檢查全部候選目標與分店查詢。

## 共用花費驗證

`node --test tests/cost-sync*.test.cjs` 驗證資料格式、離線恢復、重試與同時修改。這些測試使用模擬服務；實際部署另需用獨立測試房間檢查讀寫，不能把測試資料寫入正式共用花費。
