# 候選清單依品牌收合分店（2026/10/18）

地圖旁可捲動的清單，對有兩家以上門市的已知品牌預設顯示一個收合項目；點「展開」再查看各分店。依目前資料共10個品牌可收合，159個地圖位置對應92個預設清單項目。只有一間已核對門市的品牌及一般景點維持原卡片。

- 品牌摘要顯示名稱、符合篩選的分店數／總店數、區域及已按想去的家數。
- 分店內保留原卡片、照片、Google／Naver連結、地圖定位、來源及個別想去按鈕；不新增「整個品牌全部想去」操作。
- 搜尋、來源、區域、品牌與只看想去先篩選個別店點，再將結果收合。篩到一家分店時仍標示「1／總店數」，不把不符合的分店帶回地圖。
- 只改清單呈現；地圖仍使用符合篩選的每個店點。統計區分「清單項目」與「地圖地點」，不把收合誤算成刪除位置。
- 當頁展開狀態會在按想去、重新篩選等重繪時保留；重新整理預設收合。原本每個分店的數字ID與想去儲存格式不變，既有想去及跨裝置清單連結繼續有效。
- 地圖彈窗按「清單詳細」會自動展開該品牌、捲到對應分店並聚焦卡片；收合時也能從摘要辨識選中的品牌。鍵盤Enter／空白鍵可展開收合，分店卡片仍可用Enter定位。

本機HTTP瀏覽器驗證：全部159個標點／預設92項、10品牌預設收合、鍵盤、想去與焦點保存、分店卡片定位、地圖詳細自動展開、區域／名稱／來源／想去篩選、取消最後一個想去後移除空群組、重整保留原想去、照片與分店連結、390／1440像素排版。地圖連結與想去清單9項測試通過。原自訂花費保留，未改動行程、訂單、候選資料或共用花費。
