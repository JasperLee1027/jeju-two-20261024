# 想去清單跨裝置連結

更新日期：2026/10/18（台灣）。使用者選定不用帳號的「清單連結」方式，並接受之後各裝置修改不會自動同步。

## 網站行為與使用方式

1. 在原本有勾選紀錄的裝置開啟候選景點，按「儲存／帶到其他裝置」。
2. 按「複製清單連結」，傳給另一台裝置或旅伴。
3. 在另一台開啟，選「合併並記住（保留原有）」或「改用連結這份清單」。套用後會切換至「只看我按過想去的」，地圖縮放至這些地點。
4. 清單繼續存於該瀏覽器，重新整理可保留。之後有新增或取消想去，需重新複製並傳送更新連結；不會自動同步。

原有的 `jeju-20261024-candidates-v1` 儲存鍵保持相容，不清除先前勾選。收到連結時先預覽並讓使用者選合併、取代或關閉，不會直接覆蓋。套用或取消後會移除網址中的匯入資料，避免重新整理再次匯入舊版本。

連結只包含景點ID；不含護照、訂單、私人文件連結或帳號資訊。持有者可查看當下的想去選擇。無痕模式、清除瀏覽資料或禁止儲存可能移除／阻止本機紀錄，應保留清單連結作備份。不含待辦、花費或其他頁面狀態。

未新增雲端服務、帳號、付費項目或預訂。想去仍是候選，未變成確定行程。
