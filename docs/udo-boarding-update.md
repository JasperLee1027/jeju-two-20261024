# 牛島購票地點與搭船手續

2026/10/18（台灣）更新。網站牛島頁把購票手續移到前段，列為「找碼頭→填申報書→買票→驗票登船→回程」流程，保留原有首末班、票價、租車估價與未預訂狀態。

- 買票處：城山浦港綜合旅客碼頭內，找「우도도항선 매표소」。導航韓文「성산포항종합여객터미널」，道路地址「제주특별자치도 서귀포시 성산읍 성산등용로 112-7」；船公司舊門牌「성산리 347-9」。不是同區的牛島八景遊覽船售票。
- Naver、Google及Kakao導航連結均已列在網站，Kakao渡輪碼頭地點ID為17561678；未使用同址其他遊覽船商家的位置。
- 兩人各攜護照正本。船公司公告購票與登船都查驗身分；國際駕照屬島上租車資格，非渡輪購票所需證件。
- 現場先填乘船申報書（승선신고서），去回程各準備一份；同行資料可同表，依櫃台表格要求。照護照填英文姓名、出生日期、性別、聯絡方式，電話欄可請櫃台協助填台灣號碼。車不上船，告知兩位步行旅客。
- 持表及兩人護照買成人來回票；現行₩11,000／人、兩人₩22,000（約NT$528），已含公園入場費。保留回程票及資料，確認目的港與當日回程末班；預留45–60分鐘停車購票候船。
- 上船前確認天津港或下牛目洞港；Coconara在下牛目洞港。依船員指示驗票、出示證件登船。回程先還車，再備妥回程票、申報資料與護照排隊；不押末班。
- 網站補三句可直接出示給櫃台的韓文：買兩位成人來回票且車不上船、詢問是否往下牛目洞港、詢問回城山末班。
