# Google地圖旁補上Naver Map

2026/10/18（台灣）更新，保留原有Google地圖與照片來源。新增的是Naver Map搜尋連結，不宣稱已逐一核對Naver店家ID或營業狀態，也不變更任何帳號收藏。

範圍：

- 114個候選定位點（含61個分店位置與已付款住宿）的卡片、互動地圖彈窗。
- 6家住宿：已訂住宿按確認的韓文地址搜尋，5家舊候選按原有飯店名稱／濟州範圍搜尋。
- Google Maps照片來源連結旁及照片放大視窗；原Google照片出處與署名保留，Naver連結僅作查地點入口。
- 牛島租車店、海灘、碼頭及舊獨立牛島頁面。碼頭原有Naver連結不重複新增。
- 「複製想去清單」文字同時帶入Google與Naver連結；原有勾選、清單備份連結及景點ID不變。

搜尋優先使用候選資料中的韓文名稱。分店加上個別地址，避免都落到同品牌的泛用搜尋；有多筆結果時仍須核對地址。已付款住宿直接以確認門牌搜尋，避免把同址其他商家當住宿別名。

台灣「桃園監理站」保留Google地圖，未為台灣地點產生不適用的韓國地圖搜尋；Google Flights及其他非地圖服務不轉換。全站原有Google地圖URL均保留。

驗證：全候選資料的編碼與分店地址測試、一般Google連結不誤轉；桌面1440px及手機390px實際檢查所有候選卡、照片來源／放大視窗、地圖彈窗、品牌篩選、想去文字清單、6家住宿與牛島。初始DOM的149個Google地圖入口中，148個韓國入口均在同區提供Naver搜尋，另1個為台灣監理站。三個代表性Naver搜尋網址回應HTTP 200（這只確認入口可連線，不代表逐一確認店家資料）。另修正手機行前待辦卡片原有的最小寬度溢出。

網站發布後，同步「新濟限挑戰😗💖」專用區段並重新讀取核對，保留框外手動文字及紅字。私密同步網址與金鑰不放公開網站。
