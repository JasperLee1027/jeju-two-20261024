## 待同步至共同 Doc

- 採城山港往返牛島；船公司現行3月／10月季節表：城山出發首班08:00、末班17:30；牛島出發首班07:30、末班17:30，均為韓國時間（台灣減一小時）。約30分鐘一班，實際班次、港口及天候停航以當日公告為準，不保證10/25、10/26開航。仍建議15:30–16:00離島。
- 成人旅客去程₩6,000、回程₩5,000，來回₩11,000／人；兩人來回₩22,000，按₩1＝NT$0.024約NT$528。已含每人公園入場費₩1,000，不另加一次；本島MINI留港，不含車輛運費。
- 城山浦港綜合旅客碼頭現場填乘船申報書、出示兩人護照原件、買成人來回票，確認到達港口與回程末班，保留回程票與相關資料；預留45–60分鐘停車購票候船。購船票與租島上車輛分開。
- Coconara（코코나라，下牛目洞港附近，우목길 105）有車頂的兩人座FAMI／파미：正常價₩40,000／台（約NT$960），限量早鳥₩30,000（約NT$720）。店家標示價格於2026/9/20確認，本次10/18查閱；指定日期庫存與優惠未確認。使用至當日末班船前1小時，非24小時；若末班17:30，還車截止16:30，09:00起營業。
- 車型與三輪規格、是否接受台灣國際駕照對應類別、保險及自負額需店家確認；不能宣稱租金包含全免責。店家要求21歲以上、韓國普通駕照2種以上；海外駕照須先詢問。FAMI有85公斤以上／180公分以上限制，適用對象範圍待店家確認。未訂車、未付款。
- 正常車租參考₩40,000＋船票兩人₩22,000＋停車預留₩10,000＝₩72,000，約NT$1,728／兩人；確實取得早鳥則約NT$1,488。若仍以原本車租₩50,000–70,000保守預留，總額為₩82,000–102,000（約NT$1,968–2,448）。停車是預留額，另加餐飲、保險、超時費，不自動增加預估花費頁的已支付金額。
- 牛島仍為10/25或10/26天氣備選，示例時間軸不當作已排定行程或已確認班次。
